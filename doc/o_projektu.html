Sklik Konektor Rozcestník

O projektu

Sklik Konektor je community connector pro Google Data Studio, který umožňuje vizualizovat data z reklamního systému Sklik přímo v reportech a dashboardech Googlu.

Účel

Konektor řeší propojení mezi Skliku Drak API a Google Data Studiem. Inzerentům a analytikům umožňuje pracovat s daty Skliku stejně jako s ostatními zdroji v Google Data Studiu — vytvářet vlastní reporty, kombinovat data s dalšími systémy, sdílet dashboardy a vizualizovat výkonnost reklam.

Projekt je vyvíjen pod hlavičkou Seznam.cz, a.s. jako open-source nástroj (LGPL 2.1+).

Architektura

Konektor běží jako Google Apps Script webová aplikace, která zprostředkovává tok dat mezi Sklik API a Google Data Studiem:

Sklik API api.sklik.cz/drak/ → Apps Script konektor → Google Data Studio

Pro Google Data Studio konektor implementuje standardní funkce getConfig, getSchema, getData a getAuthType. Sklik volá přes JSON-RPC endpoint https://api.sklik.cz/drak/json/<method>.

Entity (reporty)

Konektor podporuje 7 typů reportů — pro každou entitu Sklik účtu lze načítat dimenze i metriky:

clientdata na úrovni účtu
campaignskampaně
groupssestavy (ad groups)
adstextové reklamy
bannersbannerové reklamy
keywordsklíčová slova
productsetsproduktové sety

Typ reportu se vybírá automaticky podle dimenzí požadovaných v Google Data Studiu (prefix cgc_, clc_, goc_, adc_, add_, bnc_, kwc_, pic_ v názvu sloupce).

Granularita

Data lze zobrazovat ve více časových granularitách:

Total Daily Weekly Monthly Quarterly Yearly

Granularita se vybírá automaticky podle dimenze v reportu (např. date, week, month). Chybějící časové úseky API doplňuje nulovými řádky.

Konfigurace

Uživatel při přidání konektoru v Google Data Studiu vyplňuje:

  • Token – API klíč ze Skliku (Nastavení → Získat přístup k API)
  • UserId – ID účtu, který se má sledovat
  • Typy kampaní – filtr: combined, video, context, fulltext, product, zbozi, simple
  • ID kampaní – konkrétní kampaně k načtení (volitelné)
  • ID sestav – konkrétní sestavy k načtení (volitelné)
  • ID kampaní pro klíčová slova – omezení zdroje keywords reportu
  • Zahrnout entity bez statistik – zapnutí prázdných řádků
  • Logování / Debug logování – Cloud Logging pro diagnostiku

Autentizace probíhá tokenem v konfiguraci konektoru — authType: NONE z pohledu Google Data Studia, fakticky token-based login proti Sklik API (client.loginByToken).

Limity

  • Maximálně 5 000 záznamů na jeden API call (pro time-series děleno počtem časových jednotek)
  • Maximálně 15 000 klíčových slov – u větších účtů je nutné omezit přes ID kampaní pro klíčová slova
  • Při selhání API volání proběhnou až 3 retry pokusy před zobrazením chyby uživateli

Struktura zdrojového kódu

Apps Script projekt je rozdělen do souborů podle entit a odpovědnosti:

  • main.js – vstupní body Google Data Studio konektoru (getSchema, getData, getAuthType, isAdminUser)
  • config.js – getConfig, definice konfiguračních polí
  • schema.js – schéma sloupců (dimenze, metriky, granularita)
  • root.js – orchestrace: parsování requestu, výběr reportu, volání API, retry logika
  • client.js, campaigns.js, groups.js, ads.js, banners.js, keywords.js, productsets.js – třídy pro jednotlivé entity
  • datacore.js – sdílená logika pro zpracování dat z API
  • logger.js – logování do Cloud Logging
  • tests.js – testy
  • appsscript.json – manifest (oauth scopes, Google Data Studio metadata, URL whitelist)
