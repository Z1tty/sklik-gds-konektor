Kapitola 1

Ověření domény

Proč ověření potřebujeme

Aby bylo možné publikovat komunitní konektor pro Looker Studio pod oficiální značkou Sklik, musí Google ověřit, že vlastníme doménu sklik.cz. Bez ověření Google zobrazuje u konektoru varování „neověřený vývojář" a omezuje jeho dostupnost.

Verifikační soubor pro LS 6.0.0

Google vyžaduje, aby na rootu domény sklik.cz byl dostupný verifikační soubor s následujícím názvem:

Název souboru google-site-verification=4kRvPMmSCJ6fYEYQIqAcYrtV6oVU_SRLE-_WJ0-lVd4.txt
Soubor musí být dostupný přes HTTPS na adrese https://sklik.cz/google-site-verification=4kRvPMmSCJ6fYEYQIqAcYrtV6oVU_SRLE-_WJ0-lVd4.txt a vracet HTTP 200.

Postup nasazení

  1. Verifikační soubor s výše uvedeným názvem umístit do rootu webu sklik.cz tak, aby byl veřejně dostupný přes HTTPS.
  2. Ověřit, že soubor vrací HTTP 200 a není přesměrován (curl -I https://sklik.cz/google-site-verification=4kRvPMmSCJ6fYEYQIqAcYrtV6oVU_SRLE-_WJ0-lVd4.txt).
  3. V Google Search Console / Looker Studio spustit verifikaci domény.
  4. Po úspěšném ověření soubor neodstraňovat — Google ověření periodicky obnovuje.

Změna při vydání nové verze konektoru

Verifikační token je vázaný na konkrétní verzi konektoru. Při vydání nové verze (např. LS 6.1.0) Google vygeneruje nový soubor a starý je nutné nahradit. Aktuální token pro nasazenou verzi je vždy uveden výše.

Naming convention

Názvy v Google Cloud

Pro jasnou identifikaci projektu Google Cloud odpovídajícího verzi konektoru je třeba dodržovat jednotné pojmenování:

Konvence pojmenování
Google Looker Studio - v 6xx
Poznámka: Nově se nazývá Google Data Studio - v 6xx (historicky Google Data Studio)

Projekt ID

Identifikátor projektu v Google Cloud Console:

Project ID gds-6xx

Tento ID se použije při přístupu do Google Cloud Console.
