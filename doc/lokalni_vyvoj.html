Lokální vývoj

Pro vývoj v Google Apps Script (GAS) mimo webový editor přímo ve vašem počítači (např. v editoru Cursor nebo VS Code) se používá nástroj clasp (Command Line Apps Script Projects). Díky claspu můžete kód psát lokálně, využívat našeptávání, linting a následně jej jedním příkazem nahrát do Google cloudu.

Postup nastavení (krok za krokem)

  1. Instalace Node.js

    clasp běží na platformě Node.js. Pokud jej ještě nemáte, stáhněte si LTS verzi z nodejs.org.

  2. Instalace Clasp

    Otevřete terminál (příkazový řádek) a nainstalujte clasp globálně pomocí npm:

    npm install -g @google/clasp
  3. Přihlášení k vašemu Google účtu

    V terminálu spusťte příkaz:

    clasp login

    Otevře se prohlížeč, kde potvrdíte přístup ke svým skriptům.

  4. Povolení Apps Script API

    Abyste mohli se skripty pracovat přes API, musíte jej povolit:

    • Přejděte na script.google.com/home/usersettings.
    • Zapněte možnost Google Apps Script API na „Zapnuto".
  5. Stažení existujícího projektu (nebo vytvoření nového)
    • Stažení: Najděte ID svého skriptu (v URL adrese editoru skriptu: script.google.com/d/ID_SKRIPTU/edit).
    clasp clone <ID_SKRIPTU>
    • Nový projekt: Vytvořte složku a v ní:
    clasp create --title "MujProjekt" --type standalone

Jak pracovat v Cursoru

Jakmile máte projekt naklonovaný, otevřete složku v Cursoru. Uvidíte soubory .gs. Cursor nyní bude automaticky nabízet našeptávání.

Klíčové příkazy pro vývoj

  • clasp push – nahraje lokální soubory do Google Apps Script projektu.
  • clasp pull – stáhne aktuální verzi z Google cloudu k vám do počítače.
  • clasp status – vypíše seznam souborů, které se chystají k nahrání.

Tip pro profíky: Typování (IntelliSense)

Aby vám Cursor správně napovídal metody jako SpreadsheetApp nebo DriveApp, přidejte si definice typů:

  1. V terminálu ve složce projektu spusťte:
npm install @types/google-apps-script
  1. Cursor nyní bude schopen analyzovat metody GAS a poskytne vám plnohodnotné našeptávání kódu (IntelliSense), jako byste psali v TypeScriptu.
Upozornění: Google Apps Script ve výchozím stavu používá soubory .gs (Google Script). Pokud chcete psát v čistém TypeScriptu, clasp podporuje automatickou konverzi. Stačí přejmenovat soubory na .ts a clasp je při příkazu push automaticky přeloží do JavaScriptu.
