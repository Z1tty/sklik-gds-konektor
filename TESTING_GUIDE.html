Konfigurace

Po přidání konektoru vyplň nastavení datového zdroje:

Pole Povinné Popis
Fenix token Ano Sklik → Nástroje → API přístup → Fenix token
UserId Ne ID účtu. Prázdné = konektor zjistí automaticky. Pro agenturní přepnutí zadej ID klientského účtu.
PremiseId Ne ID provozovny Zboží.cz — zatím nepodporováno, ponech prázdné.
Typy kampaní Ne Filtr na typy (vyhledávací, obsahová, video…). Prázdné = načte vše.
ID kampaní Ne Čárkou oddělená ID konkrétních kampaní. Prázdné = všechny kampaně.
ID sestav Ne Filtr na sestavy — vyžaduje vyplněná ID kampaní.
Ignorovat smazané Ne Zaškrtnuté = vyfiltruje smazané kampaně a sestavy z výsledků.

Dostupné přehledy

Konektor rozpozná typ přehledu automaticky podle prefixu pole. Do jednoho grafu nebo tabulky nekombinuj pole z různých entit.

Kampaně

Kampaň: …

Statistiky za celé vybrané období na úrovni kampaně. Konverze jsou rozepsány po typech (Purchase, Lead, AddToCart…) — každý typ tvoří samostatný řádek. Pro součtový přehled filtruj na prázdný název konverze.

Sestavy

Sestava: …

Totéž na úrovni sestavy. Obsahuje navíc metriky viditelnosti: Impression Share, Win Rate, Missed Price a další ISH metriky.

Účet

Účet: …

Souhrnný pohled na celý účet — agregát všech kampaní. Chování závisí na přidané dimenzi:

DimenzeVýsledekOmezení
(žádná)1 řádek za celé období—
Účet: Den1 řádek / denmax 31 dní
Účet: Měsíc1 řádek / měsícmax 24 měsíců
Účet: Síť3 řádky / období (Fulltext / Obsahová / Video)lze kombinovat s Dnem nebo Měsícem

Omezení aktuální verze

!
Granularita (dny / měsíce / síť) pouze pro entitu Účet. Kampaně a sestavy vracejí vždy agregát za celé zvolené období — denní nebo měsíční trend zobrazíš přes entitu Účet.
!
Inzeráty nejsou dostupné. Fenix API vyžaduje 3 vrstvené volání (kampaně → sestavy → inzeráty), která přesahují časový limit Google Data Studia.
!
PNO, CTR, Konverzní poměr — výchozí agregace SUM je vypnuta. Hodnoty v souhrnném řádku tabulky nemusí být správné. Pro přesné součtové hodnoty použij entitu Účet.
!
Výkon a API limity. Načítání při větším počtu kampaní nebo delším období může trvat 10–30 s. Při opakovaném obnovení reportu v krátkém čase může Sklik API vrátit chybu „limit požadavků" — v takovém případě počkej chvíli a obnovte report znovu.

Jak hlásit problémy

Popiš nám prosím:

  1. Jaká entita — Kampaně / Sestavy / Účet
  2. Zvolené časové období
  3. Přesný popis chyby nebo chybějících dat
